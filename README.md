# WomenBagStore - E-Commerce Application

An e-commerce web/desktop application designed for managing and browsing a women's bag store. This project demonstrates core Software Engineering concepts, including Object-Oriented Programming (OOP), Database Management, and Clean Code Architecture.

## 🚀 Features
* **Product Catalog:** Browse, search, and filter bags by category, price, and brand.
* **Shopping Cart:** Add, remove, and update item quantities.
* **User Authentication:** Secure login and registration system for customers and admins.
* **Admin Dashboard:** Manage inventory (Add/Edit/Delete products) and view customer orders.

## 🛠️ Tech Stack
* **Language:** C#
* **Framework:**  ASP.NET 
* **IDE:** Microsoft Visual Studio 2022
* **Database:** SQL Server 
## 📋 Software Engineering Practices Applied
* **OOP Principles:** Utilized Encapsulation, Inheritance, and Polymorphism for a scalable code structure.
* **SDLC Concepts:** Developed using structured stages from requirements gathering to deployment.
* **Testing:** Conducted unit testing and manual functional testing to ensure code reliability.
